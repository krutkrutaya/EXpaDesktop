## ✨ Что это

EXpaDesktop заменяет стандартный рабочий стол на собственную оболочку:
часы-гигант, слайдшоу обоев, плавающие стеклянные панели и встроенный
плеер — всё открывается и закрывается **как капля жидкого стекла**,
вырастающая из кнопки и растворяющаяся обратно в неё.

## 🌊 Жидкие анимации Liquid Glass

Анимации панелей — порт [liquid-dom](https://github.com/AndrewPrifer/liquid-dom)
/ liquid-glass на Dart, со всей физикой:

| Этап | Что происходит |
|------|----------------|
| 🟢 Открытие | Капсула кнопки стягивается в круглую каплю → капля **выстреливает** к месту панели с пружиной и случайным «толчком» (никакие два открытия не одинаковые) → разбухает до размера панели, углы распрямляются |
| 🔵 Контент | Контент виден как будто **глубоко внутри стекла** и всплывает к поверхности, пока капля растёт |
| 🔴 Закрытие | Панель сжимается обратно в каплю → капля взлетает в кнопку, растягиваясь в капсулу на лету → тает |
| ⚡ Реверс | Закрыл прямо посреди открытия — скорость переносится, капля разворачивается не моргнув |

Физика — демпфированные пружины (semi-implicit Euler, сабстепы),
прогнана мок-тестами: **32/32 PASS**, включая 200 фазз-рандомов и
stress-кадры по 300 мс.

## 🎵 Музыкальный плеер

- **Волновой слайдер** в стиле Material Design — активный трек живёт синусоидой, при перетаскивании бурлит
- Кружок-ползунок растёт при наведении и **тянется каплей** против направления движения
- 🟠 Зацикливание трека, повтор плейлиста, случайный порядок (меню `•••`)
- Кнопки пружинят как в Google Gemini: при нажатии растягиваются в овал, отпускаешь — упруго отскакивают
- Список треков — тёмное стекло с плавным затуханием краёв при скролле

## ☀️ Управление экраном

Через нативную Rust-DLL (`FFI`) — настоящее железо, не фильтры:

| Функция | Как |
|---------|-----|
| Яркость | DDC/CI `SetMonitorBrightness` + программный буст гамма-рампой сверх максимума |
| Контраст | DDC/CI `SetMonitorContrast` |
| Теплота | Гамма-рампа `SetDeviceGammaRamp` (режет синий-красный) |

Все три ползунка — на тех же волновых слайдерах, что и плеер.

## 🖥️ Оболочка

- Часы 145px, смена обоев каждые 12 секунд с кроссфейдом
- Верхняя панель со «стеклом» (BackdropFilter): приложения, мини-плеер, bluetooth / громкость / wi-fi
- Правый док с индикатором и меню питания (сон / рестарт / настройки)
- Окно настроек: 7 секций, перетаскивание за заголовок, минимизация в док, открывается на упругой пружине

## 🚀 Сборка

```bash
# 1. Flutter (https://docs.flutter.dev/get-started/install/windows)
cd ExDesktop
flutter pub get
flutter run -d windows
```

Rust-DLL уже собрана и лежит в `lib/rust/brightness.dll`.
Пересобрать при желании:

```bash
cd lib/rust
cargo build --release
cp target/release/brightness.dll .
```
